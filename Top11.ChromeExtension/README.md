# Top11.ChromeExtension

Відстежує гравців на аукціоні Top Eleven (web, Unity WebGL) через перехоплення websocket `wss://weaver.prod.topeleven.com/websocket`.

## Збірка
```
npm i -D -E esbuild@0.28.2 typescript@5.4.4 @types/chrome
npm run build      # -> dist/
npm run watch      # перезбірка при змінах
npm run typecheck
```

## Встановлення
1. `chrome://extensions` → **Developer mode**.
2. **Load unpacked** → папка `Top11.ChromeExtension/dist`.
3. Після змін: `npm run build` (або watch) → ↻ на картці розширення → перезавантажити вкладку гри.

## Структура
- `src/content/inject.ts` — MAIN world, `document_start`: хук WebSocket, буфер кадрів, звук, `window.__t11`.
- `src/content/proto.ts` — декодер protobuf без схеми.
- `src/content/bridge.ts` — міст chrome.storage/runtime ↔ сторінка.
- `src/viewer/viewer.ts` + `static/viewer.html` — переглядач усього трафіку сокета (кнопка «Трафік сокета» в попапі).
- `src/background/background.ts` — клік по іконці відкриває сторінку `viewer.html` (або перемикає на відкриту).
- `src/viewer/auction-view.ts` — вкладка «Аукціон»: Старт/Стоп, фільтри, дамп (колишній попап).
- `src/shared/messages.ts` — спільні типи.
- `static/manifest.json` — копіюється в dist.

## Дебаг у консолі вкладки гри
- `__t11.find('Bitarov')` — кадри, де є рядок, і шляхи полів.
- `__t11.state.frames[i].dec.m` — розібраний кадр.
- `__t11.dump()` — скачати всі кадри в JSON.

## Переглядач трафіку
Іконка розширення → вкладка **Трафік сокета** — відкривається вкладка з усіма кадрами websocket з моменту завантаження гри (буфер 10 000 кадрів, live-оновлення).
- **Команди** — у порядку першої появи (= що гра вантажить при старті), лічильники ↑/↓, обсяг. Клік — фільтр; назву можна вписати (зберігається); 👁 — сховати шумні.
- **Кадри** — тип (запит/відповідь/push), seq, короткий зміст.
- **Деталі** — дерево protobuf-полів з підказками (дати, великі числа), пара запит↔відповідь по seq; клік по номеру поля копіює шлях.
- Після F5 гри переглядач починає заново. **Експорт JSON** — відфільтровані кадри з назвами команд.

## Моя команда
Склад приходить у стартовій відповіді `0x0002`, поле `106` (`src/content/squad.ts`), зберігається в `chrome.storage.local.squad`.
Навички (`src/shared/skills.ts`): `(raw − 21500) / 25` + бонус рангу для ключових; неключові гра показує як 1, але в суми входять з мінусом.
ОБЩ = середнє всіх 15. Ранг — поле запису `40.1` (3 Зірковий, 4 Майстер), бонус = `40.3 × 4`. Поля 4/12 = Удари/Завершення, у воротаря — Вихід з воріт/Комунікація.

## Експорт на сайт Top11
«Моя команда» → відміть гравців → **Експорт для Top11** (JSON у буфер, формат `top11-squad`, `src/shared/export.ts`).
На сайті: команда → **Імпорт з гри** → вставити → перевірити зіставлення по імені → «Імпортувати» → «Зберегти».
`value` = `(сире − 21500) / 25` без бонусу рангу (може бути від'ємним), `tierUp` = бонус рангу, `isMain`/`isTierUp` = ключова навичка.
